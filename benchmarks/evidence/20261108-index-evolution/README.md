# Историческое сравнение внешних индексов: исходные данные

Все **12 принятых измерительных процессов**, по три парных блока на 50 тыс. и 1 млн записей. Пилотные значения не включены, исключённых результатов нет. Срезы 2021 года: 39cefe13db8697cf5f8e15edaa4677ba52a2cdea; ноября 2026 года: 09ec0703f476f25ec79baff338843df8a8e83b35. Измерительный код закреплён в [коммите ffdc186](https://github.com/Sergey303/Polar.DB/commit/ffdc186ab49d6519c1405324edcab2270ddd8ace).

Среда: Intel Core i5-12400, WSL2 Linux 6.18.33.2, .NET SDK 10.0.112, Runtime 10.0.12, Release, один хост. Порядок запусков: old/new, new/old, old/new для каждого размера; 1000 успешных запросов, Random(777), полная проверка выдачи. Кэш операционной системы не очищался. Временные файлы баз после каждого процесса удалялись.

Исходный CSV и SHA256SUMS позволяют проверить целостность и независимо пересчитать медианы командой python3 benchmarks/scripts/check-index-evolution-results.py. [Протокол](../../docs/INDEX_EVOLUTION_DIRECT_PROTOCOL_20261108.md), [отчёт и ограничения](../../docs/INDEX_EVOLUTION_DIRECT_RESULTS_20261108.md), [скрипт запуска](../../scripts/run-index-evolution-direct.sh).

Важно: prerequisite_ms версии 2026 включает обязательную подготовку первичного индекса, в версии 2021 измеряется лишь конструирование внешнего индекса. Это не эквивалентные по содержанию операции.

# Результаты контролируемого исследования page cache индекса 2021 года на GitHub-hosted Linux

**Измерено 9 ноября 2026 года; [GitHub Actions run 42593558005](https://github.com/Sergey303/Polar.DB/actions/runs/42593558005) — три Linux job SUCCESS.** Точный SHA commit исполнения `ff0f99eacc91b46cd010cd57b92e65529fd8a732`, исходный протокол и расписание зафиксированы коммитом `9ae1546`. Измерительный код не менялся. На каждой машине 40 блоков × 4 режима = 160 процессов (всего **480**), по 20 блоков на каждый из двух размеров, все приняты. Отдельная локальная 160-процессная серия не входит в числа этого архива.

Подкаталоги `ubuntu-22-x64/`, `ubuntu-24-x64/` и `ubuntu-24-arm64/` содержат **исходные** `results.csv`, `manifest.json`, `measurement-logs.tar.gz` со всеми 160 процессными журналами, `build-logs.tar.gz`, `summary.json` с анализом 20 пар на размер и `SHA256SUMS`. Исходные файлы получены из GitHub Actions artifacts без изменения числовых результатов, отдельно сверены с оригинальными логами и подписаны SHA-256 в репозитории.

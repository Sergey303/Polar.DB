# Опубликованные исходные данные подтверждающей серии 2021/2026 (9 ноября 2026)

**40/40 пар; 80/80 процессов; 20 пар на 50 тыс. и на 1 млн строк; 10 000 проверяемых успешных запросов на процесс.** Протокол и расписание были опубликованы [коммитом `ef22d0e`](https://github.com/Sergey303/Polar.DB/commit/ef22d0e70a80948c806cbd1f86f2de39c29c0117) **до запуска**. Временные файлы БД после каждого процесса удалялись, другие рабочие файлы не затрагивались.

| Файл | Назначение |
|---|---|
| `results.csv` | Все 80 первичных измерений `load_ms`, `prerequisite_ms`, `index_build_ms`, `lookup_ms`, контрольные суммы и статус проверки без исключений |
| `invocations.csv` | Время запуска и реальная продолжительность каждого процесса, порядок внутри 40 пар |
| `manifest.json` | Git SHA исходников, режим, источник runner, SHA-256 измерительных адаптеров, платформы и 80 из 80 принятых запусков |
| `measurement-logs.tar.gz` | 80 оригинальных `RESULT`-строк; проверяются построчно против `results.csv` |
| `build-logs.tar.gz` | Оригинальные журналы сборки старой и новой библиотек |
| `summary.json` | Воспроизводимые расчёты геометрических отношений и bootstrap-интервалов по 20 парным блокам на размер |
| `SHA256SUMS` | Контрольные SHA-256 всех перечисленных выше опубликованных артефактов |

Программа проверки повторно пересчитывает `summary.json` из исходных измерений, читает журналы из gzip-архива, проверяет полноту расписания, исходные SHA и совпадение каждой числовой ячейки с процессным журналом:

```shell
python3 benchmarks/scripts/verify-publication.py --only paired20
```

Для изучения исходной процедуры: [протокол](../../docs/INDEX_EVOLUTION_PAIRED20_PROTOCOL_20261109.md), [научный отчёт](../../docs/INDEX_EVOLUTION_PAIRED20_RESULTS_20261109.md), [исходник анализа](../../scripts/analyze-index-evolution-paired20.py). **Исходные числа первой трёхпарной серии (1000 поисков) не менялись**: этот опыт имеет другое число запросов и наблюдался при другом фактическом состоянии ОС/кэша. Контрольный 95%-й интервал относится к 20 процессным парам на **одном хосте** и не описывает разброс между независимыми машинами.

В каждом — неизменённые `results.csv` (80 строк), `invocations.csv` (время и порядок), `manifest.json` (версии Git/SDK, ОС и идентификаторы), `measurement-logs.tar.gz` (все 80 подлинных логов), `build-logs.tar.gz`, `summary.json` с парным анализом и `SHA256SUMS` для всех перечисленных файлов. Git-атрибуты запрещают пересчёт CRLF для этих файлов.

**Время измерялось в отдельных виртуальных машинах с разной архитектурой и файловой системой**, а не на одной полностью сопоставимой аппаратной платформе; у GitHub стандартных виртуальных машин возможна фоновая вариация CPU/хранилища. Нагрузка — 10 000 успешных поисков уникального целочисленного внешнего ключа на собственноручно созданных синтетических данных; статистическая единица — полный парный блок процессов, не единичный запрос. Один GitHub runner на ОС **не является репрезентативной выборкой всех серверов**. Доверительные интервалы отражают повторения внутри данного runner. Суммировать все 120 пар в один общий доверительный интервал или считать разницу коэффициентов между ОС причинно обусловленной только ОС нельзя.

Для пересчёта независимо от .NET и первоначального виртуального сервера:

```bash
python3 benchmarks/scripts/verify-publication.py --only hosted20
```

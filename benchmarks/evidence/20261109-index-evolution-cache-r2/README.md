# Первичные результаты адресного управления кэшем файлового индекса 2021 года

Замороженный код и порядок: [коммит `9ae1546`](https://github.com/Sergey303/Polar.DB/commit/9ae1546a72ed34cfa6826a768a8f1ab26609f53d), [протокол](../../docs/INDEX_EVOLUTION_CACHE_CONTROL_PROTOCOL_20261109.md). Запуск 9 ноября 2026: **160/160 отдельных процессов, 40/40 блоков**, 20 блоков на каждый объём и четыре режима в блоке, исходные библиотеки `39cefe13...` и `09ec0703...`, все контрольные суммы совпали. Разведочные процессы в архив не включены.

| Файл | Что содержит |
|---|---|
| `results.csv` | Все 160 результатов с порядком, режимом, проверенной резидентностью `mincore`, длительностью первых 100 и следующих 9900 поисков |
| `manifest.json` | SHA-256 кода, протокола, расписания, источники 2021/2026, платформа, завершённость, контрольная сумма CSV |
| `measurement-logs.tar.gz` | 160 исходных процессных журналов, включая оригинальные JSON `mincore` и `verified=true` |
| `build-logs.tar.gz` | Две оригинальные сборки исторических библиотек |
| `summary.json` | Отдельные медианы, 20 парных отношений, геометрические средние и описательные bootstrap-интервалы |
| `SHA256SUMS` | Побайтовый SHA-256 всех перечисленных файлов |

Для проверки полноты 160 запусков, правильных результатов, совпадения всех 160 оригинальных `RESULT` и производной статистики:

```bash
python3 benchmarks/scripts/analyze-index-evolution-cache-study.py benchmarks/evidence/20261109-index-evolution-cache-r2
```

[Научный отчёт](../../docs/INDEX_EVOLUTION_CACHE_CONTROL_RESULTS_20261109.md) описывает научный вывод и ограничения. Не путать **100% page-cache resident** с 100% в управляемой памяти приложения: пары старого индекса оставались в файле и прочитывались через файловый интерфейс, хотя страницы уже присутствовали в RAM через кэш ОС. Для других версий ОС, типов файловой системы и неуникальных ключей количественный эффект не проверен.
